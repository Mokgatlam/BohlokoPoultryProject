📋 Quick Start Instructions

1 Start Backend Server

Open a terminal and run:

cd chicken-processing-backend
node run-server.js

Note: Backend is configured to use REAL Firebase service (not emulator)

2 Start Frontend Server

Open another terminal and run:

cd chicken-processing-frontend
npm run dev
3 Or Use the Batch File

Simply double-click run-web.bat to start everything automatically.

4 Access the Application

Once both servers are running, access the system at:

Frontend: http://localhost:3000
Backend API: http://localhost:3001
